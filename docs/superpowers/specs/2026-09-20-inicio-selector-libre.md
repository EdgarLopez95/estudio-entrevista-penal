# Selector libre de estudio desde Inicio

## Objetivo

Inicio permite crear una sesión libre sin escoger duración. La persona decide primero si estudia o
practica, luego el frente y finalmente el bloque concreto.

## Flujo

1. `Estudiar` o `Practicar preguntas`.
2. `Entrevista` o `Derecho Penal`.
3. Entrevista: esenciales, Top 10, difíciles, historias STAR o mezcladas. Penal: conceptos,
   quiz, flashcards, casos o Penal esencial.
4. La selección abre el bloque completo y se conserva como sesión activa.

La recomendación automática y el selector de tiempo permanecen como sugerencias secundarias, no
como requisito para iniciar.

## Límites

- No se duplica contenido: los mismos recursos se presentan en estudio o práctica.
- Nivel 1 es el límite inicial; Nivel 2 mantiene su activación en Preferencias.
- Sesiones existentes continúan funcionando.
